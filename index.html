Prática

Estruturas condicionais

O bloco do if é executado quando a condição é verdadeira. A indentação indica quais comandos pertencem ao bloco.

if media >= 7:
    print("Aprovado")
else:
    print("Reprovado")
Caso-limite: com >=, a média exatamente igual a 7 é aprovada.

Encontre e explique os erros:

# Estação 1
nota = input("Nota: ")
print(nota + 1)

# Estação 2
media = (nota1 + nota2 + nota3) / 2

# Estação 3
if media >= 7
    print("Aprovado")

# Estação 4
if media >= 7:
print("Aprovado")
Automação

Listas e estruturas de repetição

Uma lista reúne vários valores. O for percorre os itens, um por vez.

notas = []
for i in range(10):
    nota = float(input(f"Nota {i + 1}: "))
    notas.append(nota)

soma = 0
for nota in notas:
    soma += nota

media = soma / len(notas)
print(f"Média: {media:.2f}")

IA responsável

IA como ferramenta pedagógica

1. Por que funciona?

Peça que a IA explique a propriedade usada e o que acontece se ela for removida.

2. Por que quebrou?

Peça a causa do comportamento, não apenas a correção pronta.

3. Há alternativas?

Compare vantagens, desvantagens e adequação ao objetivo.
